# コーディングサンプル：ポートフォリオサイト

## 概要
学習用デザインカンプ（はせがわ様公開）をもとに制作した、
実案件を想定したコーディングサンプルです。

デザイン素材の画像は、配布元の利用規約（再配布禁止）に基づきリポジトリから除外しています。  
表示は公開サイトをご覧ください：<https://euphonious-kulfi-8a2f71.netlify.app/>

## 使用技術
- Pug / SCSS / jQuery / webpack
- レスポンシブコーディング

### メインビジュアルスライダー
- 画面いっぱいのデザインですが、横幅の最大値はございますか。
  - 大きくなりすぎると画面の占有率が上がるので、最大幅をデザインと同じ1440pxとし、以降は左右がグレーで埋まるよう調整いたしました。
- テキストが1枚目のスライドのみになっていますが、背景の画像のみスライドする形でよろしいでしょうか。
  - 背景の画像のみスライドする形で実装いたしました。テキストをスライド内に含めることも可能です。
- ダミーテキストでデザインされており、実際のテキストに変わると画面幅によって改行が発生することが考えられます。
  - テキストのフォントサイズ、スライダーの矢印、スライダーのページネーションのサイズは親の要素に合わせて拡大・縮小する設定といたしました。
- 自動スライドは必要でしょうか。
  - 背景画像のみのスライドで、テキストを読み切る時間を考慮する必要がないため、自動スライドを設定いたしました。
- SPでは画像の表示比率が異なるようですが、デザインには1枚目の画像しかありません。
  - 1枚目の画像を複製して2枚目、3枚目に使用いたしました。必要に応じて後ほどご支給をお願いいたします。PC画像をそのまま使用することも可能です。

### 制作実績
- 掲載する実績の数は最大4件でしょうか。
  - 現状は5件以上の場合、横の間隔と同じ32pxの間隔で次の行に折り返す設定としています。行間の指定がある場合はご共有をお願いいたします。
- 長いタイトルの場合複数行になりますか。「...」等で省略になりますか。省略の場合は行数の指定をお願いいたします。
  - 現状は長いタイトルは折り返して表示しています。
- キーワードの個数が多い場合複数行になりますか。「...」等で省略になりますか。省略の場合は行数の指定をお願いいたします。
  - 現状は入力したすべてのキーワードを表示しています。
- 画像は必ず入りますか。入らない場合、デザインで使用されている画像をデフォルトとして使用してよろしいでしょうか。
  - デザインの画像をデフォルトとして設定しています。

### フッター
- SPデザインではナビゲーションが左寄せになっており、コピーライトも左右中央から少し左に寄るデザインとなっております。画面幅によって見え方が変わってきますが、コピーライトの位置は、①左右中央を基準に一定量左に寄る　②画面左端を基準にコピーライトのテキストの左側に一定量の余白をつける　のどちらの意図でしょうか。①の場合は画面が広がるほどコピーライトだけ左にずれている印象になるかと思いますので、左右中央でもよいかと思います。
